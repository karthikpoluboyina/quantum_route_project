Files to Create
FILE 1 src/quantum_router.py — Core Algorithm ▶

This file contains all the algorithm classes. Key classes inside:

CL1
ProblemGenerator
Generates random delivery nodes, vehicles, and depot coordinates
→ generate_random(n_nodes, n_vehicles, area_size, seed)
CL2
DistanceMatrix
Builds full N×N Euclidean distance matrix between all points
→ matrix[i][j] = √((x₁-x₂)² + (y₁-y₂)²)
CL3
QUBOBuilder
Encodes VRP constraints as binary optimization matrix Q where min x^T·Q·x
→ 3 penalty terms: route cost + visit-once + capacity
CL4
ClassicalSolver
Nearest-neighbor greedy heuristic — creates initial routes
→ Always picks closest unvisited node
CL5
TwoOptSolver
2-opt local search — reverses sub-routes to remove crossings. O(n²) per iter
→ optimize_route() + optimize_all()
CL6
QuantumAnnealingOptimizer
Quantum tunneling simulation — accepts worse solutions with quantum probability
→ P(accept) = exp(-ΔE / T · tunnelFactor) where tunnelFactor ∝ QAOA layers
CL7
QuantumRouteOptimizer
Main orchestrator — runs the full pipeline and returns OptimizationResult
→ optimize(nodes, vehicles, depot)
FILE 2 main.py — Entry Point (Run This!) ▶
main.py 
from src.quantum_router import ProblemGenerator, QuantumRouteOptimizer

# ── Configure your problem ─────────────────────────────
N_NODES         = 12       # delivery locations (5–25)
N_VEHICLES      = 3        # fleet size (1–6)
QAOA_LAYERS     = 5        # circuit depth (1–12)
ANNEALING_STEPS = 300      # optimization iterations
ALGORITHM       = "hybrid" # "hybrid", "classical"
# ──────────────────────────────────────────────────────

# Step 1: Generate problem
nodes, vehicles, depot = ProblemGenerator.generate_random(
    n_nodes    = N_NODES,
    n_vehicles = N_VEHICLES,
    seed       = 42,
)

# Steps 2–7: Run full pipeline
optimizer = QuantumRouteOptimizer(
    qaoa_layers     = QAOA_LAYERS,
    annealing_steps = ANNEALING_STEPS,
    algorithm       = ALGORITHM,
)
result = optimizer.optimize(nodes, vehicles, depot)
optimizer.save_result(result, nodes, depot)

Algorithm Deep Dive

QUBO ENCODING

VRP becomes: min x^T · Q · x
Each binary variable x_{i,k} = 1 means node i assigned to vehicle k.
Three penalty terms enforce constraints without explicit if-statements.

QUANTUM TUNNELING

Accept probability: P = exp(−ΔE / T · τ)
where τ = tunnel factor grows with QAOA depth p.
This lets the solver escape local minima classical SA cannot.

Parameter Reference Table

Parameter Default Effect Range
n_nodes 12 More nodes = harder problem, more qubits needed 5–25
n_vehicles 3 More vehicles = more route options, more variables 1–6
qaoa_layers 5 Higher p = stronger tunneling boost, better quality 1–12
annealing_steps 300 More steps = longer runtime but better convergence 100–1000
algorithm hybrid "classical" skips quantum step entirely hybrid / classical

Common Errors & Fixes
❌ ModuleNotFoundError: No module named 'src'
Fix: Make sure you run python main.py from inside the quantum_route_project/ folder, not from inside src/. Also ensure src/__init__.py exists.
❌ python: command not found
Fix: Try python3 main.py instead. On Windows, check that Python is added to PATH during installation.
❌ FileNotFoundError: outputs/result.json
Fix: Create the outputs/ folder manually, or the code will create it automatically on first run.
✅ Tip: Use VS Code's integrated terminal
Press Ctrl + ` to open terminal directly inside VS Code. It automatically sets the working directory to your project root.

Customize & Experiment

Use your own delivery coordinates:

main.py — custom coordinates 
from src.quantum_router import ProblemGenerator, QuantumRouteOptimizer

# Your delivery points: (x, y) — first one is the DEPOT
my_coords = [
    (50, 50),  # DEPOT (warehouse)
    (20, 30),  # Customer 1
    (70, 20),  # Customer 2
    (80, 70),  # Customer 3
    (30, 80),  # Customer 4
    (60, 50),  # Customer 5
]

nodes, vehicles, depot = ProblemGenerator.from_coordinates(
    coords     = my_coords,
    n_vehicles = 2
)

optimizer = QuantumRouteOptimizer(qaoa_layers=6, annealing_steps=400)
result    = optimizer.optimize(nodes, vehicles, depot)

Compare quantum vs classical side-by-side:

comparison experiment 
nodes, vehicles, depot = ProblemGenerator.generate_random(15, 4)

# Classical only
classical = QuantumRouteOptimizer(algorithm="classical")
r_classic = classical.optimize(nodes, vehicles, depot)

# Quantum hybrid
quantum   = QuantumRouteOptimizer(algorithm="hybrid", qaoa_layers=8)
r_quantum = quantum.optimize(nodes, vehicles, depot)

print(f"Classical: {r_classic.total_distance:.2f} km")
print(f"Quantum  : {r_quantum.total_distance:.2f} km")
print(f"Gain     : {r_quantum.improvement_pct:.2f}%")
